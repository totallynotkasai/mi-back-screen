Setup

HyperOS doesn't let normal apps draw on the rear display, so Back Screen uses Shizuku to run a few shell commands on your behalf. You set it up once.

  1. Install Shizuku

    Get it from Google Play or GitHub, and start it using wireless debugging or from a computer with ADB. Shizuku's own guide walks you through it.

  2. Install Back Screen

    Download the APK and open it. You may need to allow installing from your browser or file manager.

  3. Allow access

    Open Back Screen and tap Allow access. If the prompt doesn't appear, open Shizuku → Authorized apps and switch Back Screen on.

  4. Pick an image and switch it on

    Tap the preview to choose an image or GIF, then turn on Show on back screen. Add the tile or widget if you want a faster toggle.

FAQ

Short answers to what people usually ask.

What does Shizuku actually do here?

It runs a small, fixed set of shell commands: start the wallpaper screen on the rear display, move it there if needed, wake that display, and stop or restart Xiaomi's rear launcher. You can read every one of them in RearCommands.kt. Arguments are passed straight to the process, so nothing can be injected.

Do I need to re-start Shizuku after a reboot?

Usually yes, unless your phone is rooted. That's a Shizuku limitation. Once Shizuku is running again, Back Screen picks up where it left off.

Does it drain the battery?

The service sleeps until the rear display changes state, then re-applies the wallpaper. The rear display itself uses power when lit, just as it does with Xiaomi's own wallpapers.

Why is it not on the Play Store?

It depends on Xiaomi-specific behaviour and Shizuku, which isn't a good fit for the Play Store. The full source is on GitHub, so you can build it yourself if you prefer.

How do I build it from source?

Clone the repository and run ./gradlew assembleDebug with JDK 17 and the Android SDK installed. The APK lands in app/build/outputs/apk/debug/.
